# CET-4 四级长难句特训（English Grammar Quest）

专为大学英语四级（CET-4）备考打造的手机端交互式长难句拆解与刷题网站。全站 48 句长难句例句均精选自 **2023 年 6 月与 12 月大学英语四级真题阅读原文**。

## 核心功能
- **6 大阶段 · 24 个真题关卡**：剥洋葱抓主干 → 定语从句全破译 → 非谓语降维打击 → 四大从句与比较条件 → 倒装/强调/隐性否定 → 真题终极实战。
- **交互式拆句工作台**：每句真题支持一键切换「标出主干（主/谓/宾）」「切分修饰（定从/状从/插入语/非谓语）」「盲读模式」与「译文/考点/词汇解析」。
- **四级级实战题 + 自动错题本**：聚焦主干抓取、修饰对象识别与真题句意推理，做错自动收入错题本，支持单独刷错题。
- **手机端友好**：零外部 CDN 依赖，支持夜间模式、语音朗读与本地进度保存。
