# 英语语法闯关训练（English Grammar Quest）

面向零基础到精通的手机端英语语法闯关训练网页，配合 B 站《零基础主语法》学习路线编排，打开即可在手机或电脑上刷题通关。

## 功能特点
- **8 大世界 · 32 个关卡**：从人称代词、be 动词、五大基本句型、三大时态，一路进阶到定语从句、非谓语、名词性从句、六大修饰、倒装强调、虚拟语气与长难句拆解。
- **手机端单手友好**：底部导航栏支持「闯关地图 / 随机刷题 / 公式速查」一键切换，支持日间/夜间模式。
- **例句语音朗读**：内置浏览器英语发音朗读（🔊）。
- **本地进度保存**：通关状态自动保存在浏览器 `localStorage`，随时接着学。
